# Червь-Пожиратель

2D-игра про червя-монстра для Яндекс Игр. HTML5: Phaser 3 + TypeScript + Vite. Название рабочее.

Правила платформы, концепт и план этапов лежат в [docs/](docs/), исходники графики в [design/](design/).

## Запустить игру

Двойной клик по `play.bat`. При первом запуске он сам поставит пакеты, затем соберёт графику и откроет игру в браузере (адрес http://127.0.0.1:5173/). Чтобы остановить, закройте чёрное окно.

То же из терминала: `node tools/dev.mjs --open`. Нужен Node.js 20 или новее (стоит 24 LTS).

### Управление

| Где | Как |
|---|---|
| Мышь | червь плывёт к курсору |
| Клавиатура | стрелки или WASD (по физическим клавишам, работает и с русской раскладкой) |
| Телефон | палец: червь плывёт к точке касания, палец отпустили — держит курс |
| Прыжок | доплыть до поверхности: червь выпрыгивает; чем выше тир и ступень крыльев, тем выше прыжок |
| Пауза, звук | кнопки в углу, а также `Esc` или `P`, и `M` |

Червь без команд не стоит, а держит курс. Съедобна добыча не крупнее пасти: крупнее червь пока не проглотит.

**Отладочная панель** (слева внизу) есть только при запуске для разработки. Через неё меняют персонажа, ступень крыльев, рост, включают автопилот и сбрасывают сохранение. В собранную игру она не попадает.

## Собрать архив для Яндекс Игр

```
npm run pack
```

Собирает игру, проверяет правила архива Яндекса (`index.html` в корне, имена латиницей, ≤ 100 МБ, пути относительные, нет `sdk.js` внутри, нет адресов S3) и кладёт `build/worm-game-<версия>.zip`. Если правило нарушено, архив не создаётся и скрипт говорит, какое.

Проверка самого архива в условиях, близких к боевым (вложенный путь, SDK из корня сайта, запуск без SDK): `python tools/test_dist.py`.

## Автопроверки

```
node tools/dev.mjs                 # в одном окне: сервер игры
python tools/test_game.py          # в другом: 70+ проверок в скрытом Edge
python tools/test_game.py --only sdk,save,resize
```

Проверяют загрузку, рост, прыжок, крылья, персонажей, паузу, звук, язык, обращения к SDK, сохранение, размеры окна (в том числе 4K, 21:9 и узкое окно) и касания. Снимки для просмотра глазами пишутся в `build/shots/`.

## Устройство проекта

```
src/
  platform/   SDK Яндекса (вне Яндекса подставляется имитация), сохранения: локально сразу, в облако с паузами
  core/       язык, звук (Web Audio), раскладка экрана, управление, общее состояние
  data/       персонажи, рост по тирам, улучшения
  game/       червь, добыча, фон, эффекты
  scenes/     Boot (загрузка), Game (мир), UI (шкала, кнопки, пауза)
  dev/        отладочная панель (только при запуске для разработки)
tools/        генераторы SVG, конвейер атласов, сборка ZIP, автопроверки
design/       исходники графики (SVG), превью, манифест
docs/         правила Яндекса, концепт, дорожная карта
public/assets/  атласы, создаются из design/ при запуске и сборке (в git не хранятся)
```

Правило для кода: вся работа с платформой идёт только через `src/platform/platform.ts`, сохранения через `src/platform/save.ts`, звук через `src/core/audio.ts`, тексты через `src/core/i18n.ts`. Всё отладочное спрятано за `import.meta.env.DEV` и в релиз не попадает.
