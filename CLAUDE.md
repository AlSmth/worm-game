# Проект: игра про червя-монстра для Яндекс Игр

HTML5-игра (2D, вид сбоку, стиль «флеш») для платформы Яндекс Игры. Общение с пользователем и документация на русском. Имена файлов и папок только ASCII, без пробелов и кириллицы (п. 1.22 требований: действует и для `design/`).

## Обязательные документы (читать перед любой работой)

- [docs/YANDEX_REQUIREMENTS.md](docs/YANDEX_REQUIREMENTS.md) — правила Яндекс Игр. **Нарушать нельзя ни одно.** Если задача или правка конфликтует с правилом, сначала предупредить пользователя и предложить вариант без нарушения. Идею меняем, правило нет.
- [docs/GAME_CONCEPT.md](docs/GAME_CONCEPT.md) — концепт. Живой документ: любые изменения от пользователя сразу вносить туда и в журнал изменений. 👤 — идея пользователя, 💡 — предложение Claude.
- [docs/ROADMAP.md](docs/ROADMAP.md) — этапы Э0…Э8, статусы, открытые решения.
- [design/README.md](design/README.md) — стиль, технические правила ассетов, устройство червя.
- [design/ASSETS.md](design/ASSETS.md) — манифест всех визуальных элементов и их статус.
- Улучшения: три линии по 5 ступеней. Прыжок даёт крылья (ряд автора: жук, птица, светлые, тёмные, золотой дракон), здоровье даёт броню (чешуя превращается в рога), скорость даёт гребень и плавники (вопрос Q11). Базовый червь без деталей, первая покупка линии открывает деталь. **Слова «ангел», «демон», «ад», нимбы, кресты, пентаграммы, руны нельзя** (пп. 3.4.2, 3.4.5, риск R14): образ сохраняем, названия нейтральные.
- В игре три выбираемых персонажа-червя (`peach`, `salad`, `plum`), отличаются только внешним видом. Модель червя: гладкая трубка без соединений (рисуется кругами вдоль пути головы) и две большие челюсти; размер челюсти определяет, какую добычу можно съесть. Части генерирует `tools/gen_worm.py`, крылья `tools/gen_upgrades.py`, броню и гребень `tools/gen_gear.py`, добычу `tools/gen_prey.py`, сокровища `tools/gen_treasure.py`, эффекты `tools/gen_fx.py`, фон зоны 1 `tools/gen_zone1.py`, зону 2 (люди, дома, машины, техника охраны, декор, фон) `tools/gen_zone2.py` (SVG руками не править). Превью дизайна: `design/preview/index.html` (сервер `design-preview` в `.claude/launch.json`).
- Данные баланса лежат в `src/data/`: `growth.ts` (таблица масштабов червя по тирам, очки роста, экономика), `prey.ts` (размеры подземной добычи по тирам, абсолютные), `treasure.ts` (сокровища, глубина), `upgrades.ts` (цены и бонусы улучшений, полёт на крыльях по ступеням), `challenges.ts` (испытания), `surface.ts` (добыча поверхности: реальные размеры, очки, монеты, вес по тирам, охрана и ракеты, здоровье и урон), `world.ts` (карта, тир выхода на поверхность).
- Масштаб: мир в реальных пропорциях (человек 1500 px, машина 3900, небоскрёб 36 000, жуки до 200 px). Растёт червь (`wormScale(тир)`), камера отъезжает (вид ∝ масштаб^0,85 в `GameScene`), карта растёт вместе с червём (`worldHalf`). В проверках расстояния и глубины задавать в «пикселях масштаба 1» и умножать на масштаб червя (`far()` и `place()` в `test_game.py` делают это сами).
- Поверхность (зона 2): `src/game/Surface.ts` (люди бегут, машины ездят, охрана целится и стреляет ракетами с самонаведением, залпы, декор), взрыв `Fx.boom`, здоровье и оглушение в `GameScene.ts`, полоса здоровья и окно «Заново» в `UIScene.ts`. Над землёй кусать можно, только когда пасть над землёй.
- Магазин: `src/scenes/ShopScene.ts` (поверх игры, игра на паузе), кнопка и подсказки в `UIScene.ts`, испытания считает `src/game/Challenges.ts`. Покупка сохраняется сразу через `save.patch`.
- Мир: числа ширины карты (≈ 5 минут от края до края для червя 1-го тира) и тира выхода на поверхность (T5) лежат в `src/data/world.ts`; пока выход закрыт, червь скользит под травой.

## Технический стек и команды (с Э2)

Phaser 3.90 + TypeScript 5.9 (strict) + Vite 7, сборка в ES2015 (старые устройства, п. 1.20). Node.js 24 стоит в `C:\Program Files\nodejs`; если `node` не находится, добавить в PATH на время команды (PowerShell: `$env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')`; Bash: `export PATH="$PATH:/c/Program Files/nodejs"`). Подробности запуска и структура: [README.md](README.md).

- Сервер разработки: `node tools/dev.mjs` (сначала собирает атласы, порт 5173; в `.claude/launch.json` это конфигурация `game`). Игроку: `play.bat`.
- `npm run typecheck` · `npm run build` (атласы, tsc, vite) · `npm run pack` (build + `tools/pack.py`: проверка правил архива и `build/worm-game-<версия>.zip`).
- Автопроверки: `python tools/test_game.py [--only имя,…]` (нужен запущенный dev-сервер; драйвер браузера `tools/cdp.py` управляет скрытым Edge без внешних библиотек) и `python tools/test_dist.py` (проверка собранного ZIP). После любой правки кода прогонять обе; новые поведения сразу покрывать проверкой.
- Графика: SVG в `design/` → `tools/build-assets.mjs` → атласы и одиночные картинки (фоны) в `public/assets/` (не в git). Новый набор SVG подключается добавлением строки в `ATLASES`, повторяющаяся плитка или фон — в `SINGLES` (размер степень двойки).
- Скрипты на Python с соседними импортами (`cdp.py`, `test_game.py`) запускать без `-I`.
- Автопроверки: начальное сохранение подкладывать через `seed_chosen()` или `seed_shop()` (монеты, улучшения, испытания; скрипт до запуска игры), а не через `localStorage` перед перезагрузкой: уходящая страница пишет своё сохранение поверх. `boot()` сам выбирает персонажа на экране выбора.

Правила кода:
- Платформа (SDK, пауза, язык, реклама) только через `src/platform/platform.ts`; сохранения только через `src/platform/save.ts` (локально сразу, облако не чаще раза в 4 с: лимит `setData` 100 за 5 мин); звук только через `src/core/audio.ts`; тексты только через `src/core/i18n.ts` (RU/EN, без текста в картинках).
- Отладочное (`window.__dev`, `window.__platform`, панель, подсказки) только под `import.meta.env.DEV`: в боевой сборке его быть не должно (п. 1.14); проверяет `tools/test_dist.py`.
- Любое новое поведение держим в рамках правил: пауза и тишина при потере фокуса и рекламе, управление одной рукой, поле не шире 2:1, сохранение по действию игрока.

## Рабочее соглашение

- Работаем **строго по этапам** из ROADMAP.md. К следующему этапу не переходить без явной команды пользователя («Начинай этап N»).
- В конце этапа: что сделано · как проверить · проверка по правилам Яндекса (какие пункты затронуты) · вопросы. Обновить статусы в ROADMAP.md и ASSETS.md.
- «Зона» (1–4, финал) — часть игрового мира; «этап» (Э0–Э8) — шаг разработки. Не смешивать.
- Не добавлять в игру ничего, чего нет в концепте, без согласования; предложения помечать 💡.
- Перед выпуском нового этапа сверяться с чек-листом (раздел 5 в YANDEX_REQUIREMENTS.md) по затронутым пунктам.

## Самое важное из правил (полный список в YANDEX_REQUIREMENTS.md)

- Платформенные функции (реклама, вход, язык, сохранения) только через SDK Яндекса; сторонней рекламы, чужих платёжек, внешних ссылок нет.
- Звук и игра на паузе при потере фокуса и при полноэкранной рекламе. Звук только через Web Audio API (без `<audio>`/`<video>`).
- Сохранение по действию игрока, не по таймеру; переживает F5 и поворот; работает для гостя.
- Нет прокрутки, pull-to-refresh, выделения, контекстного меню; поле на ПК не шире 2:1; управление на телефоне одним пальцем.
- Контент: без политики, войн и конфликтов, религии, флагов и эмблем, крови, детей и пожилых как добычи; червь дружелюбный. Техника вымышленная, без символики.
- В графике нет текста; все строки через словарь RU/EN; язык берём из `ysdk.environment.i18n.lang`.
- Реклама только на стыках (итоги, магазин, «Заново», «Далее»), никогда посреди захода.
- Никаких «demo», версий, отладочных надписей на экране; ZIP ≤ 100 МБ, `index.html` в корне, пути относительные.
- Всё авторское: сторонние материалы только с коммерческой лицензией и записью об этом.
