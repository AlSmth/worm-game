# Проект: игра про червя-монстра для Яндекс Игр

HTML5-игра (2D, вид сбоку, стиль «флеш») для платформы Яндекс Игры. Общение с пользователем и документация на русском. Имена файлов и папок только ASCII, без пробелов и кириллицы (п. 1.22 требований: действует и для `design/`).

## Обязательные документы (читать перед любой работой)

- [docs/YANDEX_REQUIREMENTS.md](docs/YANDEX_REQUIREMENTS.md) — правила Яндекс Игр. **Нарушать нельзя ни одно.** Если задача или правка конфликтует с правилом, сначала предупредить пользователя и предложить вариант без нарушения. Идею меняем, правило нет.
- [docs/GAME_CONCEPT.md](docs/GAME_CONCEPT.md) — концепт. Живой документ: любые изменения от пользователя сразу вносить туда и в журнал изменений. 👤 — идея пользователя, 💡 — предложение Claude.
- [docs/ROADMAP.md](docs/ROADMAP.md) — этапы Э0…Э8, статусы, открытые решения.
- [design/README.md](design/README.md) — стиль, технические правила ассетов, устройство червя.
- [design/ASSETS.md](design/ASSETS.md) — манифест всех визуальных элементов и их статус.
- Улучшения: три линии по 5 ступеней (прыжок даёт драконьи крылья, здоровье даёт броню, скорость даёт чешую). Базовый червь без деталей, первая покупка линии открывает деталь. Стиль: драконья фантастика, без пентаграмм, рун, религиозных знаков и слов «демон»/«ад».
- В игре три выбираемых персонажа-червя (`peach`, `salad`, `plum`), отличаются только внешним видом. Их части генерирует `tools/gen_worm.py`, улучшения `tools/gen_upgrades.py` (SVG червей и улучшений руками не править). Превью дизайна: `design/preview/index.html`, сервер `design-preview` в `.claude/launch.json`.

## Рабочее соглашение

- Работаем **строго по этапам** из ROADMAP.md. К следующему этапу не переходить без явной команды пользователя («Начинай этап N»).
- В конце этапа: что сделано · как проверить · проверка по правилам Яндекса (какие пункты затронуты) · вопросы. Обновить статусы в ROADMAP.md и ASSETS.md.
- «Зона» (1–4, финал) — часть игрового мира; «этап» (Э0–Э8) — шаг разработки. Не смешивать.
- Не добавлять в игру ничего, чего нет в концепте, без согласования; предложения помечать 💡.
- Перед выпуском нового этапа сверяться с чек-листом (раздел 5 в YANDEX_REQUIREMENTS.md) по затронутым пунктам.

## Самое важное из правил (полный список в YANDEX_REQUIREMENTS.md)

- Платформенные функции (реклама, вход, язык, сохранения) только через SDK Яндекса; сторонней рекламы, чужих платёжек, внешних ссылок нет.
- Звук и игра на паузе при потере фокуса и при полноэкранной рекламе. Звук только через Web Audio API (без `<audio>`/`<video>`).
- Сохранение по действию игрока, не по таймеру; переживает F5 и поворот; работает для гостя.
- Нет прокрутки, pull-to-refresh, выделения, контекстного меню; поле на ПК не шире 2:1; управление на телефоне одним пальцем.
- Контент: без политики, войн и конфликтов, религии, флагов и эмблем, крови, детей и пожилых как добычи; червь дружелюбный. Техника вымышленная, без символики.
- В графике нет текста; все строки через словарь RU/EN; язык берём из `ysdk.environment.i18n.lang`.
- Реклама только на стыках (итоги, магазин, «Заново», «Далее»), никогда посреди захода.
- Никаких «demo», версий, отладочных надписей на экране; ZIP ≤ 100 МБ, `index.html` в корне, пути относительные.
- Всё авторское: сторонние материалы только с коммерческой лицензией и записью об этом.
